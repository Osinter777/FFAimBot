# Free Fire Aimbot

Продвинутое Android-приложение, реализующее систему аимбота для Free Fire с использованием TensorFlow Lite, разрешений Shizuku, а также функций оверлея и записи экрана.

## ⚠️ Правовая оговорка

Этот проект разработан **исключительно в образовательных целях** и для демонстрации продвинутых Android-технологий. Использование данного приложения в онлайн-играх может нарушать условия обслуживания и привести к блокировке аккаунта. Используйте на свой страх и риск.

## 🚀 Функционал

### Основные возможности
- **Aimbot с ИИ**: обнаружение целей с помощью TensorFlow Lite
- **Плавающий оверлей**: панель управления поверх игры
- **Запись экрана**: захват геймплея в высоком качестве
- **Разрешения Shizuku**: доступ к привилегированным функциям системы

### Технические характеристики
- Обнаружение объектов в реальном времени
- Отзывчивый пользовательский интерфейс
- Настраиваемые параметры
- Оптимизация производительности
- Поддержка множества разрешений экрана

## 📋 Требования

### Необходимое ПО
- Android Studio 4.0+
- Android SDK API 21+ (Android 5.0+)
- Java Development Kit (JDK) 8+
- Gradle 7.0+

### Требования к устройству
- Android 5.0+ (API 21+)
- Разрешение на оверлей
- Установленное и настроенное приложение Shizuku
- Минимум 2 ГБ ОЗУ
- Процессор с поддержкой операций с плавающей точкой

## 🛠️ Установка

### 1. Настройка окружения
```bash
git clone https://github.com/Osinter777/freefireaimbot.git
cd freefireaimbot
```

2. Настройка Android SDK

```bash
export ANDROID_HOME=/path/to/android-sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
export PATH=$PATH:$ANDROID_HOME/platform-tools

sdkmanager "platform-tools" "platforms;android-34"
```

3. Сборка проекта

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

📱 Настройка на устройстве

1. Установка Shizuku

1. Скачай и установи Shizuku
2. Включи режим разработчика
3. Включи отладку по USB
4. Запусти Shizuku через ADB:

```bash
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

2. Необходимые разрешения

· Наложение поверх других окон (SYSTEM_ALERT_WINDOW)
· Захват экрана (MediaProjection)
· Доступ к хранилищу
· Разрешения Shizuku

3. Первичная настройка

1. Открой приложение Free Fire Aimbot
2. Перейди в настройки
3. Выдай все необходимые разрешения
4. Настрой параметры аимбота
5. Проверь оверлей до запуска в игре

🎮 Как использовать

Запуск аимбота

1. Первичная настройка: открой приложение, настрой разрешения, отрегулируй чувствительность и уверенность.
2. Активация оверлея: нажми «Запустить оверлей» — появится плавающая панель.
3. Использование в игре: открой Free Fire, используй панель для управления аимботом.

Управление оверлеем

· AIM: включить/выключить аимбот
· SET: открыть настройки
· REC: начать/остановить запись экрана

Расширенные настройки

· Чувствительность: скорость движения аимбота (0–100%)
· Уверенность: минимальная точность для обнаружения (0–100%)
· Визуальные цели: показать/скрыть боксы
· Прицел: показать/скрыть центральный крестик

🔧 Архитектура проекта

Основные компоненты

· AimbotManager — управление моделью TensorFlow Lite, обработка кадров, обнаружение целей, расчёт движений.
· OverlayService — создание плавающего оверлея и интерфейса.
· ScreenRecorder — захват экрана через MediaProjection, запись видео.
· ShizukuHelper — работа с API Shizuku.
· TargetOverlay — отображение обнаруженных целей и прицела.

Поток данных

```
Захват экрана → TensorFlow Lite → Обнаружение целей → Визуальный оверлей
                                            ↓
Настройки ← Интерфейс пользователя ← Управление оверлеем
```

· Прицел: включён

🐛 Решение проблем

Частые проблемы

· Оверлей не появляется — проверь разрешение на наложение, перезапусти приложение.
· Аимбот не работает — проверь модель TensorFlow и разрешения Shizuku.
· Запись не идёт — дай разрешение на захват экрана, проверь место.
· Низкая производительность — снизь качество видео, закрой другие приложения.
